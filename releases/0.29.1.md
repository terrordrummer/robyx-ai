# Robyx 0.29.1

**CI portability patch.** The `0.29.0` runtime is unchanged. This patch fixes
two Unix smoke assertions that assumed the current test process would always
be named `python`. GitHub Actions executes the locked `pytest` console script
directly, so Linux correctly exposes `pytest` through `/proc/<pid>/comm` and
`ps -o comm=`.

The tests now verify the real process utility contract: a live Unix PID
resolves to a non-empty process name, independently of launcher spelling.

## Migration and compatibility

There is no data or runtime migration. `bot/migrations/v0_29_1.py` is the
required no-op step that keeps the version chain continuous. The release is
non-breaking and intended as the immediate successor to `0.29.0`; the
published `v0.29.0` tag remains immutable.
